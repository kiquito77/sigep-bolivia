QUE ES EL SINCON?

 

El Sistema Integrado de Contabilidad "SINCON", es un sistema de registro de las transacciones diseñado de manera exclusiva para Instituciones Públicas, integra la información presupuestaria, patrimonial y de tesorería, para apoyar el proceso de toma de decisiones de los ejecutivos del sector público.

El SINCON está basado en los Principios de Contabilidad Generalmente Aceptados y los preceptos contables.

 

 

Es recomendable  tener una base conceptual sólida en el Sistema Integrado de Contabilidad, para el manejo del SINCON.
