MANTENIMIENTO RELACIONADORES

 

Esta opción permite al usuario realizar listados y consultas sobre los diferentes relacionadores que utiliza el sistema, como ser: Relacionador Cuentas y Partidas, Cuentas y Rubros, Fuentes de Financiamiento y Organismos Financiadores, OEC, Gastos y Recursos.

 

Al ingresar por ejemplo a la opción Gastos-Contabilidad el sistema presentará la siguiente pantalla:

 

Las funciones de Modificar, Insertar y Borrar están deshabilitadas.

 

 

El sistema presenta la relación de las cuentas de la contabilidad patrimonial, con las partidas presupuestarias, con el clasificador económico de gastos y se define el tipo de la cuenta, si es Presupuestaria P o Financiera F,  además de el tipo de apertura programática.

Las teclas de función tienen el mismo comportamiento restrictivo de acuerdo a recomendaciones y seguridad del sistema.
