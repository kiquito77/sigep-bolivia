FORMAS DE INGRESAR AL SINCON

 

Desde el escritorio de Windows:

 

Para ingresar al sistema SINCON desde el escritorio de Windows, se recomienda utilizar el acceso directo que el instalador crea por defecto.

 

Otra opción es a través de la Opción Inicio del Windows de la siguiente manera:

 

 

 

Las dos opciones u otras que existen ingresamos al sistema y la primera pantalla que nos mostrará es la siguiente:

 

 

Al iniciar el sistema, SINCON pide la identificación del usuario y la contraseña.

Por defecto el usuario es SINCON y no se tiene contraseña

 

Una vez instalado el sistema en el computador por defecto se crea el usuario SINCON, el mismo se considera como super-usuario de la base de datos, ingresando con el mismo a todas las opciones de menú establecidas en el sistema.

 

 

Importante: El sistema no contempla contraseña inicialmente, para el usuario SINCON, sin embargo por seguridad en el futuro se recomienda crear la correspondiente contraseña o password.
