ANÁLISIS DE CUENTAS AUXILIARES

 

La secuencia de comandos es la siguiente:

 

 

Las cuentas auxiliares tienen movimientos que el sistema le va ha enseñar, tan solo con digitar las teclas correspondientes. Son el compendio de las cuentas que el Usuario ha creado para el desarrollo específico de su trabajo.

Activando esta opción se obtiene otro submenú con las opciones Simples y De Agregación.

 

ANÁLISIS DE AUXILIARES SIMPLES

 

Seleccionada esta opción se despliega la pantalla que se muestra a continuación.

 

La pantalla muestra todas las cuentas para las cuales se ha creado auxiliares individuales o de entrada.  Al lado derecho se encuentran los datos de la cuenta seleccionada.

 

El botón imprimir le permite obtener un reporte de todas las cuentas con sus respectivos auxiliares previa elección del rango de fechas.

El botón salir permite cancelar la operación retornando a la pantalla anterior.

El botón Seleccionar le permite ingresar el criterio de selección para una cuenta y posterior análisis de sus auxiliares. Para poder obtener el reporte del mayor de Auxiliares correspondiente a la cuenta seleccionada, los pasos a seguir son similares a los descritos a continuación, es decir, después de haber ingresado el criterio de selección, elegir aceptar para visualizar la cuenta y a continuación poder realizar el análisis de sus auxiliares.

Seleccionada una cuenta con la tecla <Enter> o doble clic con el ratón, por ejemplo la cuenta 11124 que corresponde a Cunetas Fiscales y Otras en la Banca en M/N, se despliega la siguiente pantalla.

 

 

En el lado izquierdo se visualiza el listado de las cuentas auxiliares  y al lado derecho los datos correspondientes a estas cuentas .

 

Con ayuda de las teclas de direccionamiento posicione el cursor sobre una de las cuentas auxiliares, seguidamente digite la tecla <Enter> o doble clic con el ratón, para luego ingresar el rango de fechas y pulsar a continuación botón aceptar desplegándose la pantalla del reporte.

 

Puede darse el caso que después de haber sido seleccionada una cuenta auxiliar, el sistema le indique que: esta es una cuenta de agregación y no de entrada, debiendo entonces seleccionar otra cuenta, o que la cuenta no tiene movimiento en el rango de fechas seleccionada. 

A continuación podrá obtener por pantalla un reporte similar al siguiente del Libro detallado de Auxiliares, conteniendo únicamente el movimiento de la cuenta auxiliar seleccionada.

 

ANÁLISIS DE AUXILIARES DE AGREGACIÓN

 

Seleccionada esta opción se despliega la pantalla que se muestra a continuación.

 

Al lado izquierdo se encuentra la lista de las cuentas con auxiliares de agregación y al lado derecho se encuentran los datos correspondientes a la cuenta seleccionada.

 

Con el botón imprimir le permite obtener un reporte del Libro detallado de Auxiliares conteniendo todas las cuentas con sus respectivos auxiliares, previa elección de rangos de fecha.

El botón salir le permite cancelar la operación retornando a la pantalla anterior.

El botón Seleccionar le permite ingresar el criterio de selección para una cuenta y posterior análisis de sus auxiliares. Para poder obtener el reporte del Libro detallado de Auxiliares correspondiente a la cuenta seleccionada, los pasos a seguir  después de haber ingresado el criterio de selección, botón aceptar para visualizar las cuentas y a continuación poder realizar el análisis de sus auxiliares.

Seleccionada una cuenta con la tecla <Enter> o con doble clic con el ratón, por ejemplo la cuenta 11124 que corresponde a Banco, se despliega la siguiente pantalla.

 

Al lado izquierdo se encuentra la lista de los auxiliares de agregación y al lado derecho se encuentran los datos correspondientes al auxiliar seleccionado.

 

Con ayuda de las teclas de direccionamiento posicione el cursor sobre una de las cuentas auxiliares, seguidamente digite la tecla <Enter> o doble clic con el ratón, para luego ingresar el rango de fechas y pulsar a continuación aceptar desplegándose el reporte.

 

Puede darse el caso que después de haber sido seleccionada una cuenta auxiliar, el sistema le indique que esta es una cuenta de agregación y no de entrada, debiendo entonces seleccionar otra cuenta. O indicarle el sistema que la cuenta no tiene movimiento en el rango de fechas seleccionada. 

A continuación podrá obtener el reporte del Libro detallado de Auxiliares.

Eligiendo imprimir le permite obtener un reporte del Libro detallado de Auxiliares, desplegando todas las cuentas auxiliares correspondientes a una cuenta, previa selección de rangos de fecha.

El botón Seleccionar, le permite ingresar el criterio de selección seguidamente digitar aceptar para ingresar el rango de fechas.

El botón cancelar le permite cancelar la operación retornando a la pantalla anterior.
