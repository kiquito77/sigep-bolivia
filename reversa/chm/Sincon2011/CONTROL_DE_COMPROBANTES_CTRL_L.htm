CONTROL DE COMPROBANTES - CTRL+L

 

Opción resumen que permite realizar todas las opciones que componen este menú de comprobantes, la elección debe realizarse como sigue:

 

Al ingresar a la opción de CONTROL se presenta lo siguiente:

Pantalla que muestra la opción Control de comprobantes, a través de la cual, se puede realizar registros nuevos, modificaciones, validaciones, copiados de comprobantes, etc.

 

Esta opción presenta las siguientes columnas:

 

Cbte

Se indican los números de los comprobantes, los cuales se registran correlativamente.

Fecha

Corresponde a la fecha de registro de la transacción

Codtr

Código de transacción usado en el comprobante

Beneficiario

Nombre de la Persona o entidad, ya sea proveedor o acreedor, referida en el comprobante.

Total Debe/ Total haber

Mostrará los Importes totales de la transacción correspondientes a los débitos y créditos.

 

Dentro del CONTROL DE COMPROBANTES encontrará la siguiente información, desplegada en la parte inferior.

 

Comprobante

Indica el número asignado al registro realizado.

Fecha

Fecha en el siguiente formato: dd/mm/aaaa, en la cual se realizó la transacción en el sistema.

 

Tipo de cambio

 

El tipo de cambio de la moneda con la cual esta trabajando, a la fecha en la cual se realiza la transacción.

Estado

Indica el estado actual del comprobante, pudiendo ser borrador, por completar o validado.

Usuario

Indica nombre  o descripción del usuario.

Código de

Transacción

Muestra el código y descripción del código de transacción.

Caso

Corresponde a la codificación alfabética que coloca el sistema a las posibilidades que tiene un mismo código de transacción.

Beneficiario

La descripción del beneficiario

Glosa

Es la explicación del comprobante y/o operación detallada, en algunos casos mencionando la documentación de respaldo a las transacciones efectuadas.

 

El CONTROL DE COMPROBANTES, presenta las siguientes posibilidades referentes a esta  opción:

 

F1 Ayuda

Le brinda información  referente a los campos de trabajo (Columnas)

 

Modificar

Permite modificar cualquier campo que desee dentro del registro elegido Recuerde que no puede modificar un comprobante VALIDADO. Para realizar esta operación debe situarse en la fila de cualquier comprobante y con doble “clic” con el ratón o con “enter” con el teclado se podrá realizar la edición del comprobante elegido.

Permite realizar un registro.

 

Permite borrar un comprobante que no este validado. Al digitar esta tecla el sistema le consulta si desea confirmar el borrado o no el Comprobante.

Al seleccionar la opción No, la operación de Borrado se cancela. Si digita Si, borra el Comprobante. No se puede borrar un comprobante validado

Permite seleccionar comprobantes según criterios.

 

Consultar

Permite la consulta del comprobante, sin la opción a modificación. Para realizar esta operación debe situarse en la fila de cualquier comprobante y con doble “clic” con el ratón o con “enter” con el teclado se podrá realizar la consulta del comprobante elegido, este en borrador o este validado.

Permite desplegar y/o imprimir ya sea en pantalla o impresora.

Permite validar el comprobante. 

Otorga la posibilidad de realizar una copia idéntica de un comprobante que se encuentra en Borrador o Validado, obteniendo de esta manera una copia en borrador

Permite la reversión del comprobante elegido.

Permite ordenar los comprobantes por fecha o por número de comprobante.

Permite llevar la lista de los comprobantes con todas sus características a una hoja electrónica (excel)

 

Opción Modificar

Ejecutando esta opción con doble clic  con el ratón o  con enter con el teclado en el comprobante a modificar se ingresa al registro donde se puede modificar la transacción a realizar.

Opción Nuevo

Eligiendo la opción NUEVO <F3>, se puede ingresar un comprobante, el sistema le solicitará realizar la clasificación de la transacción es decir el código del comprobante a registrar.

Posteriormente se despliega la pantalla, donde se realizará el asiento, con lo que se inicia el proceso de elaboración del comprobante de contabilidad, debiendo ingresar primeramente los datos del encabezado y luego el cuerpo del comprobante.

Para una mejor comprensión de los campos del encabezado así como del cuerpo del comprobante, referirse a la explicación dada en ANEXO (Campos de un comprobante).

 

Opción Borrar

Digitando la tecla <F4> o eligiendo la opción Borrar, el sistema le pregunta si desea borrar o no el Comprobante seleccionado. Con NO, la operación de borrado se cancela. Con SI,  se borra el comprobante.

 

Recuerde que no se puede borrar un comprobante Validado.

 

 

Opción Seleccionar

Al digitar la tecla <F5> o elegir la opción Seleccionar, puede Usted seleccionar el (los) comprobante(s) de acuerdo al criterio de selección. Activando esta tecla, se despliega la pantalla que a continuación se mostrará.

 

 

En esta pantalla se puede realizar búsquedas de comprobantes, por rango de fechas, beneficiario, Códigos de transacción, el estado (1 = Borrador, 2 = Por Completar, 3 = Validado O * = Todos), usuario y Tipo de Cambio.

Opción Imprimir

Al Digitar <F7> o elegir la opción Imprimir, se despliega una ventana donde deberá seleccionar las características de la impresión del comprobante.

Pantalla que muestra las características definidas para la impresión del comprobante elegido.

 

Pudiendo obtener por pantalla un reporte similar al siguiente, luego de haber seleccionado las Opciones en la Impresión del Comprobante.

 

 

Opción Validar

Al digitar <F8> o elegir la opción Validar, el sistema le consulta <Si> desea Validar el Comprobante seleccionado. Con <NO> la operación de Validación es cancelada, con SI se inicia el proceso automático de Validación, asignándole el Sistema un nuevo número.

Opción Copiar

Al digitar <F9> o elegir Copiar, tiene la posibilidad de realizar la copia de un comprobante seleccionado cuando éste se encuentre Validado o No, copiando como Borrador.

Después de  seleccionar el Comprobante y digitar la tecla <F9>, el sistema le consulta <SI> desea copiar o <NO> el comprobante seleccionado. Con <NO> cancela la operación, con <SI> el sistema inicia el proceso de copia, indicándole finalmente el número asignado al comprobante copiado como borrador.

Opción Revertir

Eligiendo esta opción el sistema revierte el comprobante elegido y graba esa reversión en borrador.
