MANEJO DEL SISTEMA

 

OPCIONES 

Existen opciones uniformes en el Sistema, en todos los procesos que se realizan en el paquete, las más características son:

 

Ayuda (F1)

 

 

Permitirá acceder a la información de ayuda referente al proceso que realiza y/o opera y a otras ayudas dependiendo del lugar en que se solicita la ayuda.

 

Modificar

Permite realizar modificaciones en el registro elegido. En pantalla se despliega una ventana con los distintos campos a modificar; el cursor se situará en la primera letra del primer campo, pudiendo el Usuario del Sistema realizar modificaciones en los campos del archivo en el que esta trabajando.

El cursor no puede ser ubicado en aquellos campos no modificables. Para  grabar los cambios  realizados elegir grabar. Para cancelar cualquier cambio elegir salir.

 

Insertar

Añadir un nuevo registro a su archivo.

En pantalla se abrirá una ventana dentro del cual el sistema le pedirá los distintos campos del nuevo registro. El cursor no se situará en aquellos campos que el sistema calcula o coloca automáticamente; no pasará de aquellos campos que tengan que ser llenados necesariamente, saliendo el correspondiente mensaje.

 

Borrar

Borra cualquier registro que usted elija, colocando el cursor sobre dicho registro; antes de borrarlo, en la parte superior-derecha aparece un mensaje de confirmación de si está seguro o no. Debe digitar <N> si no desea borrar dicho registro y <S>  si lo desea.

 

 

 

 

Si digita <S> el registro será borrado sin opción a recuperación.

 

Seleccionar

Selecciona lo requerido de acuerdo a las variables que se definan. Luego de la elección tendrá en pantalla una ventana con los distintos campos del archivo en el cual se encuentra trabajando, cada uno con un asterisco (*) reemplaza letras ó números  por delante. Se podrá colocar la(s) letra(s) y/o número(s) comunes de los registros que desea seleccionar.

 

Ascendente /

Descendente

Permite sortear las cuentas, clasificadores, relacionadores u otros planes de manera ascendente o descendente.

 

 

Ordenar

Permite ordenar de acuerdo a la variable elegida, puede ser partida, cuenta, OEC, etc.

 

 

Imprimir

Permite imprimir el listado que ve en pantalla o los datos de algún registro, el cual elegirá colocando el cursor sobre dicho registro y digitando <aceptar> o <clic> con el ratón; esto depende del módulo en el que se encuentre.

Eligiendo Imprimir el sistema por defecto le presenta inicialmente la vista previa del reporte documento o listado a imprimir y eligiendo la impresora manda el reporte a papel.

 

 

 

 

En los distintos Anexos-Reportes podrá ver las salidas por impresora.

 

Grabar

 

Grabar cualquier alta, modificación o elección que haya realizado. 

 

Salir

Salir de cualquier opción a la que haya entrado

 

 

 

 

 

 

 

INFORMACIÓN DE PANTALLA

 

En cada una de las pantallas usted encontrará la siguiente información dentro de un cuadro.

 

Registros

Es el número de registros que se encuentran activos del archivo en el cuál está  trabajando.

 

Orden

Es el orden ascendente o descendente en el que se encuentra el archivo, según el campo en el que esté ordenado.

 

Campo

Es el campo por el cuál se encuentra ordenado el respectivo archivo.

 

OPERATIVIDAD DEL SISTEMA

 

Iniciado el sistema desplegará una serie de pantallas, según digite o escoja las opciones presentadas en el menú principal.

 


El menú principal, está conformado por las opciones de Comprobantes, Reportes, Módulo Gerencial, Mantenimiento y Utilitarios y Ayuda; pudiendo elegir una de éstas con ayuda de las teclas de direccionamiento o digitando simultáneamente las teclas correspondientes a cada opción (<Alt +  primera letra de la opción>). Cuando se seleccione una de estas opciones, se desplegará submenús que a su vez contienen otras opciones. Podrá seleccionar una de estas sub-opciones de diferentes formas:

 

            -           Digitando la letra mayúscula remarcada o resaltada (tecla nemotécnica)  de la opción.

            -           Utilizando las flechas de direccionamiento, debiendo posicionar el cursor sobre la opción elegida, para luego activar la opción digitando la tecla <Enter>.

            -           Digitando simultáneamente las teclas indicadas para cada opción (atajos con CTRL+……)

            -           Utilizando el ratón, haciendo clic

 

Cuando el cursor se encuentra sobre una opción, ésta se encuentra resaltada

 

 

Con la opción Comprobantes se ingresa al menú que corresponde a Trascripción, Modificación, Validación, Borrado, Impresión, Control de comprobantes, entre otros. Con la opción Reportes, se realiza los reportes de contabilidad, presupuestos y tesorería. En la opción Reportes Gerenciales, a reportes para ejecutivos y en la opción mantenimiento, se accede a realizar las personalizaciones al sistema o la verificación de los instrumentos que el sistema utiliza para su operatibilidad.
