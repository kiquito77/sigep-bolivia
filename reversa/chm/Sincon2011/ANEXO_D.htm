ANEXO D

         CAMPOS DE UN COMPROBANTE

 

CABECERA DEL COMPROBANTE

 

Cuando usted desee trabajar en un comprobante, después de haber seleccionado el código de transacción, se despliega la pantalla siguiente, correspondiente a la cabecera del comprobante:

 

Esta pantalla presenta los siguientes campos:

 

 

 

Beneficiario

Es el nombre o razón social de la persona o entidad pública o privada que provee o acredita la transacción

Cod. Transacción

Indica el código de transacción elegido para el comprobante

Unidad Ejecutora

Muestra el código de la unidad ejecutora para la cual se esta generando el comprobante.

Moneda

Se especifica el código de la moneda con la que se está trabajando, por defecto bolivianos (BSS)

Dólar y UFV

Especifica el tipo de cambioque es dado automáticamente por el sistema, pero también puede ser dado por el usuario, en este caso el sistema desplegará el siguiente mensaje de confirmación.

Si la respuesta es afirmativa, el sistema acepta las modificaciones realizadas en el tipo de cambio, del dólar y/o de la UFV,  podrá continuar el Usuario con la introducción de datos en la cabecera del comprobante. Si la respuesta es negativa se despliega el siguiente mensaje y luego se restaura automáticamente el cambio del sistema.

Vuelva a introducir el cambio, o < enter > para continuar

Fecha

Especifica la fecha del comprobante; la misma que muestra la fecha actual, pero puede cambiarse a la fecha que se desee, en el siguiente formato: dd/mm/aaaa. El sistema está programado para verificar que la fecha esté en el margen del año actual por lo cual si coloca una fecha incoherente saldrá el siguiente mensaje de error.

La fecha no es valida

Doc. de respaldo

Se especifica el documento de respaldo del comprobante introducido.

Nro. de

comprobante

Es generado por el sistema automáticamente, cuando el comprobante es creado,se consignará Nuevo, al grabar en borrador, el número empieza en 1 y con 0 si se valida el registro.

 

CUERPO DEL COMPROBANTE

 

Al  terminar de llenar los datos de la cabecera del Comprobante (recomendable, pero puede llenarse también al final) podrá continuar con el Cuerpo del Comprobante, como puede observar en la pantalla siguiente.

 

Al pie de la pantalla se encuentra la descripción de los campos, Línea, Apertura, Gas/Rec, OEC, Cuenta y Auxiliar; descripción que se va mostrando a medida que se introduce los datos. En la parte inferior derecha se encuentran los totales de los Débitos y Créditos que van generando en el comprobante, así como la diferencia de ambos.

En la pantalla anterior, encuentra usted las columnas de:

 

 

 

Apertura Programática

Especifica el código de la apertura programática de la partida de gastos, correspondiente al programa, proyecto, actividad u obra a la cual desea afectar con el gasto.

Si coloca un código inexistente obtendrá el mensaje siguiente.

 

           

Se puede utilizar la tecla <F6> para este campo o doble clic con el ratón.

               

Al digitar <F6>, se abrirá la siguiente pantalla de elección de Apertura Programática.

 

 

Una vez seleccionada la Apertura Programática con ayuda de la tecla <Enter> o con doble clic, el cursor se trasladará a la columna de gastos según su elección.

En caso de elegir un código de Apertura Programática de un nivel alto, en el que no se puedan realizar imputaciones, se presentaran mensajes de error, similares a los siguientes.

 

 

 

Gasto

En el campo gasto, debe introducir el número del código de la partida de gasto que será afectada. Este es un código de cinco dígitos, pero si el usuario digita un código menor a cinco dígitos el Sistema asumirá que los demás dígitos son ceros. Código que será validado contra la partida de presupuesto de gastos. En caso de digitar un código incorrecto, el sistema le indica que:

 

           

Si no se recuerda los códigos de gastos se puede utilizar la tecla <F6> o doble clic, en la que se muestra las partidas relacionadas con la apertura programática seleccionada anteriormente.

 

La siguiente pantalla se obtiene luego de digitar la tecla <F6> o hacer doble clic.

 

Luego de seleccionar el código de la partida de gastos con ayuda de la tecla <Enter> o con doble clic, se despliega la ventana que se muestra a continuación, donde deberá ingresar el monto a ejecutar en moneda nacional o extranjera e indicar si es un débito o un crédito, pudiendo desplazarse de uno a otro con ayuda de la tecla <Tab> o con el ratón y seleccionar digitando la tecla <Enter> o con clic.

 

 

 

 

Recurso

En el campo recurso, debe digitar el código del rubro de recursos que será afectado. Este es un código de cinco dígitos, pero si el usuario introduce un código de menor tamaño, el sistema asume que los demás dígitos son ceros. Se valida contra el rubro de presupuesto de recursos.

En caso de digitar un código incorrecto, el sistema le indicará que:

 

 

Si desea puede usar la tecla <F6> o con doble clic, para elegir un rubro de recursos.

 

La siguiente pantalla se obtiene luego de digitar la tecla <F6> o hacer doble clic. Donde deberá elegir el código del rubro de recursos, luego ingresar el monto a ejecutar en moneda nacional o extranjera e indicar si va al Debe o al Haber, como se puede observar a continuación.

 

           

 

Si elige la misma combinación de códigos de Apertura Programática, gastos o recursos, cuentas y OEC igual a una ya seleccionada, el sistema le dará el siguiente mensaje de error.

 

 

 

 

Cuenta          

Es el código de la cuenta que será afectada, por determinada transacción, que se validará contra la tabla plan de cuentas  y/o, tabla de relaciones entre partidas de gasto,  clasificador económico y códigos de Tesorería.

En este campo debe digitar el código de la cuenta que desee afectar.

 

 

 

 

 

 

Si no recuerda los códigos de cuentas puede utilizar la tecla <F6> o doble clic, y tendrá una lista de las distintas relaciones existentes.

 

Debe tomarse nota que cuando la partida o rubro presupuestario tiene una sola relación en la Contabilidad patrimonial, el sistema de manera automática llenará el campo de cuenta, si la relación es más de una con <F6> o con doble clic deberá elegir la cuenta correcta. A continuación se muestra la pantalla que el sistema presenta cuando solicitamos con <F6> o con doble clic el listado de cuentas relacionadas con esa partida:

 

Si el código de la cuenta es erróneo tendrá el siguiente mensaje.

Usted debe tener conocimiento del código de cuenta que desea afectar en particular.

 

Si digita un código de cuenta que no pertenezca al tipo de operación que desee realizar tendrá el siguiente mensaje:

Es decir, usted debe tener una información real y concreta de la operación que desea realizar, tanto como los códigos de los mismos.

Luego de introducir el código correcto el cursor se ubicará en el campo siguiente a pedir, según el código de transacción en el que esté trabajando.

 

 

Cuenta Auxiliar

Se especifica el código de la cuenta auxiliar, asociada a la cuenta de contabilidad. Se valida contra la tabla de auxiliares y la relación entre cuentas y auxiliares.

En este campo debe digitar el código de una cuenta auxiliar de la cuenta de contabilidad o con <F6> o con doble clic para visualizar la pantalla que se muestra a continuación.

 

 

Si digita un código de una cuenta auxiliar errónea, el sistema le indica:

Como se explicó anteriormente, debe tener información suficiente para realizar cualquier operación. 

Si no digita ninguna información en este campo tendrá el mensaje siguiente:

Al digitar correctamente el número del código de la cuenta auxiliar, encontrará la ventana que se muestra a continuación, o bien el siguiente mensaje:

Después de digitar las teclas Ctrl+F7 se despliega la pantalla siguiente.

 

 

En esta pantalla deberá introducir todos los datos requeridos para la creación de un auxiliar. Finalmente elegir grabar.

Antes de finalizar la transacción debe ingresarse la GLOSA del comprobante, que debe contener 10 o más caracteres, en caso contrario el sistema le indicará:

Luego introducir la glosa puede grabar el comprobante, en pantalla se despliega la ventana que a continuación se muestra y en al que se verifica la cuadratura del comprobante.

 

 

 

Posteriormente se presentará la pantalla en la que tiene la opción de grabar el comprobante, como Borrador o Por completar, como se muestra a continuación:

 

 

Si el Comprobante no cuadra el sistema presentará la siguiente advertencia:

 

 

Si decide continuar se presentará la siguiente pantalla:

 

 

 

Si desea grabar el comprobante como Incompleto, es posible grabar el comprobante hasta donde esta y luego se lo pueda modificar para que cuadre, y grabarlo como Borrador.
