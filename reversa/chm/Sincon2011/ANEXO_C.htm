ANEXO C

EXPLICACIÓN DE TECLAS ESPECIALES

TRANSCRIPCIÓN DE COMPROBANTES

 

 

 

F1

 

Ayuda.

Al presionar F1 se presenta una pantalla de Ayuda referente al campo donde esta situado el cursor.

F2

 

Cambiar.

Para utilizar esta tecla debe posesionarse sobre los campos del DEBE o del HABER al presionar F2 el sistema traslada el monto del Debe al Haber o viceversa. 

F3

 

Insertar Filas.

Esta tecla se usa para insertar filas vacías en el comprobante, al presionar F3 el sistema pregunta cuantas líneas desea añadirse al comprobante.

Esta tecla debería usarse cuando se desea insertar una fila en medio de dos con datos ya introducidos, o cuando sabemos a priori que el comprobante tendrá más de 10 líneas.

Ctrl+N

Insertar una fila.

Se usa para insertar una fila a continuación de la posición del cursor, útil cuando se vincula comprobantes y el sistema ancla las filas vinculadas.

F4

 

Borra la fila actual.

Borra la fila donde esta situado el cursor, es importante recalcar que se borra físicamente la fila más su contenido. 

Ctrl+F4

Borra el contenido de la Fila Actual.

Esta tecla limpia la fila actual, es decir borra todos los códigos presentes en la fila actual pero la fila permanece aún dentro el comprobante. 

Ctrl + F7

 

Presenta Pantalla de Totales.

Al Presionar Ctrl.+F7 el sistema presenta una pantalla con las sumas totales y parciales distinguiendo la Contabilidad, Gastos y Recursos.  

F6

 

Presenta Lista de Selección.

Al presionar esta tecla se presenta una lista de opciones o códigos validos, en ella se escoge la fila deseada y se presiona <Enter> para confirmar la entrada o [ESC] para cancelar la operación. 

Ctrl + F7

 

Creación de Auxiliares.

Esta tecla se usa para Crear Auxiliares, para ello es necesario que el cursor este sobre la columna de auxiliar de otro modo el sistema informará que no puede realizar la operación. 

CTRL+F6

Consultar Comprobantes.

Esta tecla es de uso obligatorio en los siguientes casos:

-           Si se quiere Devengar un Compromiso Anterior.

-           Si se quiere Pagar un Devengado Anterior.

-           Si se registra un Ingreso a Caja de un Devengado Anterior

Para ello el sistema presenta una lista con los comprobantes habilitados para ese efecto. Es utilizada en códigos de Transacción 10, 11 y 19.

Grabar.

Este botón se usa para grabar el comprobante, para ello el sistema revisa que todas las filas estén completas y además que el comprobante cuadre si así lo exige el código de transacción. Si el Comprobante no se puede cuadrar por algún motivo (alguna partida no esta habilitada o no tiene montos suficientes) el sistema pregunta si se desea grabar el comprobante como Incompleto, vale decir con esta opción es posible grabar el comprobante hasta donde esta y luego se lo pueda modificar para que cuadre y entonces grabarlo como borrador. 

Cancelar.

Esta tecla abandona la introducción del Comprobante. Sale sin grabar.

Shift + F3

Lista Clasificadores Presupuestarios de Gastos y de Recursos, dependiendo de la Columna en la que se está situado

Ctrl + F3

Datos Cheque, cuando se sitúa en la columna auxiliar y en cuentas de banco
