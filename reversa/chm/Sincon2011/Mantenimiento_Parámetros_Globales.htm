DATOS GLOBALES 

 

La secuencia de menús será la siguiente:

Ingresando a esta opción, el sistema nos presenta la siguiente pantalla:

 

 

Datos Globales que permiten personalizar los reportes y otras salidas del sistema

Está constituida por los siguientes campos:

 

Gestión

Es el año en el que se trabajará con la información presupuestaria  de la contabilidad general y de administración financiera de la institución.

Papel

Pre-Impreso

Sirve para la impresión de comprobantes, donde se deberá especificar si la impresión del comprobante se realizará en un formulario preimpreso [S] o caso contrario [N] lo realizará en otro tipo de formulario, teniendo el sistema que poner encabezado.

Nivel Control

Controles que utiliza el sistema para evitar sobregiros

Institución

Es el código institucional y la descripción de la institución.

Sigla

Establecido por el estado para cada empresa o institución.

Teléfonos

Teléfonos de la Institución.

Población Censal

Número de habitantes según censo de población(en el caso de municipalidades y prefecturas)

Pagina web

URL de la página web

Email 

Correo lectrónico de la institución

Cuenta Almacén

Corresponde al primer dígito del grupo de gastos que se apropia para los gastos de almacenes. (Código contable Patrimonial)

Cuenta Bancos

Es el código de la cuenta contable que corresponde a bancos.

Cuenta Caja

Código contable Patrimonial para la cuenta Caja.

Apertura

Corresponde al Programa 99000000 en el que se ejecutarán las partidas financieras que se mueven por flujo.

Fuente

La Fuente de financiamiento que mostrará en el reporte que se envié a la Contaduría para el  flujo financiero

USUARIOS DEL SISTEMA 

 

La secuencia en el menú será la siguiente:

 

 

Esta opción permite crear usuarios, por defecto el usuario SINCON es el usuario administrador, pero se pueden de acuerdo a las necesidades dar de alta nuevos usuarios y asignarles una clave de acceso o Password.

Activando esta opción se despliega la siguiente pantalla.

 

El usuario SINCON es el administrador del sistema, dispone de todas las opciones, no debe borrarse.

 

Esta pantalla esta constituida por los siguientes campos:

 

Usuario

Corresponde al nombre del usuario del sistema.

Descripción

Detalle del usuario.

 

La opción duplicar permite la asignación de tareas a un usuario. (Copiando los espacios de otros usuarios) Pudiendo tener un usuario una o más tareas asignadas.

 

 

 

En la parte derecha de esta pantalla se tienen las siguientes funciones:

 

Modificar

Esta opción permite modificar el código y su descripción.

Con grabar realiza las modificaciones en este campo

Insertar

Esta función permite ingresar un nuevo registro, debiendo ingresar el Usuario y su descripción.

Borrar

Permite borrar un registro siempre y cuando no sea un código restringido. Con ayuda de las teclas de direccionamiento (flechas) o mediante las teclas <PgDn> o <PgUp> podrá desplazar el cursor hasta posicionar sobre la cuenta (registro) que desea borrar. Eligiendo Borrar y después de confirmar, el sistema automáticamente eliminará el registro.

Imprimir

Esta función permite determinar el destino y característica del Reporte.

Asc/Desc

Permite ordenar los registros en función al campo que se visualiza en forma ascendente o descendente.

Contraseña 

Permite asignar el código de seguridad (Password) para cada usuario.

ASIGNACIONES OPCIONES MENÚ 

 

La secuencia en el menú será la siguiente:

 

Activando esta opción se desplegará  la pantalla que se muestra a continuación, donde se pueden observar los siguientes campos:

Esta opción permite al administrador del sistema, asignar tareas a los otros usuarios o restringirlas.

 

Usuario

Usuario del sistema.

Tarea

Tarea asignada.

 

En la parte derecha de esta pantalla se tienen las siguientes funciones.

 

Modificar

Esta opción permite modificar los campos del Usuario y la Tarea.

Insertar

Esta función permite ingresar un nuevo registro debiendo ingresar el usuario y la tarea asignada a este.

Borrar

Permite borrar un registro.

Con ayuda de las teclas de direccionamiento (flechas) o mediante las teclas <PgDn> o <PgUp> podrá desplazar el cursor hasta posicionar sobre la cuenta (registro) que desea borrar. Digitando Borrar y después de confirmar, el sistema automáticamente eliminará el registro.

Imprimir

Esta función permite determinar el destino y característica del Reporte.

 

Asc/Desc      

Permite ordenar los registros en función al campo que se visualiza en forma ascendente o descendente.

Orden

Permite ordenar los registros por los campos de Usuario o por la tarea asignada a este usuario.

 

Eligiendo Imprimir y después de determinar las especificaciones de la impresión, se obtiene por pantalla el reporte que se muestra a continuación.
