FLUJO DE EFECTIVO

 

Eligiendo este menú se presenta la siguiente pantalla:

 

Reporte Esta opción premite reportes , por unidad ejecutora o consolidados, por fuente, rango de fechas y en tres formatos.

 

La ventana de dialogo anterior, permite al usuario definir diferentes características del reporte o flujo de caja

 

Tipo

Permite identificar el reporte a nivel consolidado o a nivel unidad ejecutora por defecto, el sistema realiza el reporte únicamente para la unidad ejecutora activa.

Informe

por Fuente

Permite discriminar el uso de fuentes de financiamiento en las transacciones que afectan caja o bancos, solo es posible para la opción Flujo de Caja Estándar.

Alcance Fechas

Permite seleccionar el rango de fechas para las cuales el sistema procesa la información, por defecto del primer día del mes vigente a la fecha con el formato dd/mm/aaaa

Reporte

El sistema permite la elaboración del movimiento del efectivo bajo dos formatos de flujo de caja, el estándar de acuerdo a rubros y partidas presupuestarias y el formato requerido por la Unidad de Programación Fiscal, que es el formato TGN, por códigos OEC.

Con imprimir el sistema inicia el proceso de elaboración del reporte, según las características especificadas en la pantalla de dialogo.
