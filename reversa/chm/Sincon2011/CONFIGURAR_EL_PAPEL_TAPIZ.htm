CONFIGURAR EL PAPEL TAPIZ

 

SINCON permite al usuario configurar o personalizar a su agrado el papel tapiz, es decir el fondo de la pantalla principal, dependerá de la creatividad de cada usuario obtener un fondo que puede estar relacionado con la Institución, por defecto el SINCON tiene el siguiente fondo.

 

Pantalla inicial del SINCON, cuyo fondo es personalizable, el usuario puede colocar el tapiz que desee.

 

 

Para personalizar el fondo, el usuario debe crear en cualquier software (incluido el paint de windows. La única condición es que el archivo tenga el siguiente nombre y la siguiente extensión:

Sincon2008.png

Creado el archivo debe copiarlo al siguiente directorio:

SWP2008

Puede guardar varios archivos, cambiando temporalmente el nombre.
